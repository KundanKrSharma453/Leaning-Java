## 💡 Example

```java
public class StringExample {

    public static void main(String[] args) {

        String name = "Java";

        System.out.println("Language: " + name);
        System.out.println("Length: " + name.length());
        System.out.println("Uppercase: " + name.toUpperCase());
    }
}
```

### Output

```text
Language: Java
Length: 4
Uppercase: JAVA
```
